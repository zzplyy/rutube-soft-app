# RuTube Soft — постоянный адрес мини-приложения

Страница-переходник для кнопки «Приложение» в Telegram-боте RuTube Soft. Программа на ПК публикует
текущий адрес своего туннеля (подписанный ключом ПК), страница проверяет подпись и открывает приложение.
Здесь нет кода программы, ключей входа и данных — только открытый ключ для проверки подписи.
